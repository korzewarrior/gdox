# GP57EB40 PB00 experimental interface

GDOX includes an experimental Windows USB interface for the exact identity
`HL-DT-ST DVDRAM GP57EB40 PB00` at USB `0e8d:1887`. It accepts only the tested
XGD2 Wave 2 geometry. Original Xbox, XGD2 Wave 1, XGD3, other revisions, and
other host platforms are unsupported for this profile.

## Physical validation

On 2026-09-08 UTC, Hexode connected this drive through the Windows diagnostic
tool with the same XGD2 Wave 2 disc used for the ASUS DRW-24D5MT investigation.
The visible stock last LBA was 2723, with 2048-byte sectors and PFI layer
geometry `03 08 6F`.

Read-only probes identified the distinct firmware's capacity, geometry,
auxiliary, and neighboring guard fields. A one-byte capacity reduction changed
READ CAPACITY from 2723 to 2722; restoring it returned the drive to stock.
Volatile activation then exposed a valid game descriptor and directory.
Repeated 32-sector samples across both layers matched. The probe verified
all changed fields, unchanged guards, stock capacity/PFI, and readiness after
restoration.

The compiled GDOX source also opened this drive through the diagnostic
transport and exposed 3,825,924 sectors. Its 65-sector read matched the earlier
ASUS capture; abort followed by close restored all six changed bytes. Separate
readbacks verified all 13 mutable/guard bytes, stock capacity, and readiness.
A contiguous 6 MiB probe read completed in 40.883 seconds through the relay;
this is not a native USB throughput benchmark. READ(10) and READ(12) returned
identical descriptors, and the root/XEX identity matched Assassin's Creed
(title ID `555307D4`).

Native desktop gameplay and disconnect/reconnect recovery remain unvalidated.
No support for other media layouts is inferred from shared USB IDs or similar
LG model names. Credit to Hexode for the drive access and testing.

## Exact state

| Field | XDATA addresses | Stock bytes | Live bytes |
| --- | --- | --- | --- |
| Capacity | `8A37–8A39` | `03 0A A3` | `3D 61 03` |
| Layer geometry | `8BE2–8BE4` | `03 08 6F` | `20 33 9F` |
| Auxiliary guard | `8538–853A` | `64 00 64` | unchanged |
| Read-only guard | `8BE5–8BE8` | `00 FC F9 C3` | unchanged |

The address layout matches GP65 PB00, but this is an independent exact-drive
profile restricted to its physically tested media. GDOX verifies identity,
media, and known volatile state before activation. Unknown states fail closed.
Activation writes capacity before geometry; restoration writes geometry
before capacity. Each triplet is written in ascending address order and read
back. Auxiliary and fixed guard fields are never written or repaired.
Reads are limited to 32 sectors, the current speed is retained, and tray
handling is manual. Firmware, EEPROM, and disc contents are never written.
Raw diagnostic captures remain in the private research workspace.
