gdox / release / windows

gdox is portable on windows and reads the drive through the stock microsoft storage driver.

download

gdox-0.1.0-x86_64-pc-windows-msvc.zip — 11 MB. includes xemu and a blank xbox hdd.

unsigned: smartscreen will warn. choose more info, then run anyway.

check it before installing:

curl -O https://gdox.korze.org/downloads/0.1.0/SHA256SUMS
curl -O https://gdox.korze.org/downloads/0.1.0/SHA256SUMS.minisig
curl -O https://gdox.korze.org/minisign.pub
minisign -V -p minisign.pub -m SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing

source: gdox and xemu. the same files are attached to the v0.1.0 release on github.

requirements

  • 64-bit windows 11
  • a compatible stock dvd drive
  • your own 512-byte MCPX 1.0 rom and compatible xbox bios

leave the stock cd-rom and usb storage drivers on the drive. do not install winusb, zadig, or any third-party optical driver.

setup

  1. extract the complete windows archive.
  2. open the extracted folder and run gdox.exe.
  3. open sources and add your mcpx rom and bios.
  4. connect the drive, then insert an original xbox disc.
  5. wait for the game name, then choose start xemu.

keep the folder together. it holds the matching xemu runtime and a blank hdd.

your hdd, settings, firmware, and saves live in your appdata folder, so replacing the release folder leaves them alone.
