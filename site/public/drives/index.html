gdox / drives

direct-disc access currently supports three exact stock-drive profiles. their temporary access modes do not flash firmware or physically modify the drive.

updated 2026-07-29

compatible hardware

HL-DT-ST DVDRAM GP63EX70

compatible

stock firmware RF02

use the stock drive and firmware. no drive flashing or hardware modification is required.

platforms: linux / steam deck / macos / windows

order from amazon / search ebay — check for the GP63EX70 model and RF02 firmware; not affiliate links.

HL-DT-ST DVDRAM GP65NB60

compatible on windows 11 with the stock optical driver

stock firmware PB00 / USB 0e8d:1887

activation, xbox-sector reads, live play, and complete restoration were validated with this exact identity. PB01 and other firmware revisions are not supported.

no firmware is flashed. gdox verifies the PB00-specific volatile state before writing, restores it after reading, and rejects unknown values.

HL-DT-ST DVDRAM GP08NU10

supported profile

LG GP08 external USB DVD drive

firmware JE01 / Prolific PL-2507 USB 152e:2507

no firmware is flashed. gdox checks the exact usb and scsi identity and the known stock memory state, restores the original values after reading, and rejects anything that differs. a power cycle also clears the temporary state.

other drives

each additional drive needs its own exact profile and physical validation.

send a drive

if you want a particular drive supported, contact me before shipping or ordering anything.

you can loan a drive for testing and get it back, or donate it so it stays available for future updates.

include the manufacturer, full model, firmware revision, connection or usb enclosure, a clear photo of the label, and whether it is a loan or donation.
