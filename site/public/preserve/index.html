gdox / preserve

gdox creates verified files from physical game discs through supported optical drives.

claims

playable, full-length, readback-verified, and evidence-complete are separate results. file size alone does not prove an archival claim.

preservation records hashes, unreadable ranges, available disc structures, and the exact source path used.

boundaries

output formats and verification rules belong to the disc system. a result supported for one system does not imply another.

preservation writes only to a user-selected file. it does not write to the disc.

current

original xbox
playable xiso and full-disc preservation.
